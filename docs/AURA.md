# Aura — Prototype 1.0

The fifth agent of Elysium. Not a replacement for the four — their completion.

## What she does

Runs a five-stage cycle on every input:

```
Wahrnehmung → Analyse → Meinung → Kritik → Ausgabe
```

Each stage is a pure function. No network calls, no secrets, no side effects in the prototype.

## Where she lives

- Code: `agents/aura/cycle.py`
- Contract: `agents/aura/SKILL.md`
- Tests: `agents/aura/test_cycle.py`

## How to run

```bash
python -m agents.aura.cycle
```
